# 🎮 Guess the Number – My First Python Adventure!

### 🐍 Python vs. Your Brain 🧠

Welcome to my first Python mini-project!

The computer is hiding a secret number between **1 and 50**, and your mission is to guess it.

Sounds easy? Well, your brain might disagree! 😂

## 🎯 How to Play

1. The computer secretly picks a random number (1–50).
2. You enter your best guess.
3. The computer gives you hints:
   - 📉 **Too Low!** – Aim higher, genius!
   - 📈 **Too High!** – Calm down, Einstein!
   - 🏆 **You Won!** – Congratulations, Sherlock!
4. Keep guessing until you win!

## 💻 Example Gameplay

```text
Guess the lucky num: 10
Too Low

Guess the lucky num: 40
Too High

Guess the lucky num: 25
Too Low

Guess the lucky num: 30
You won. game Over!!

Thank you for playing.
```

## 🚀 How to Run

Make sure Python is installed on your computer.

```bash
python practice.py
```
